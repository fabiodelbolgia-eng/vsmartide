# vsmartide
# 📱 Local Mobile IDE for Android

**IDE mobile 100% locale per Android con IA integrata. Genera codice, approva i Diff e sincronizza su GitHub/SSH dallo smartphone.**

Questo repository è dedicato esclusivamente alla distribuzione ufficiale dell'applicazione. Il codice sorgente è chiuso (Closed Source), ma puoi scaricare e utilizzare l'app gratuitamente.

## ✨ Funzionalità Principali

*   **🤖 Agente IA Integrato (LLM-First):** Interagisci con il tuo progetto tramite chat in linguaggio naturale. L'IA legge l'albero dei file e propone le modifiche.
*   **🔑 BYOK (Bring Your Own Key):** Nessun abbonamento nascosto. Inserisci la tua API Key di Google Gemini, OpenAI o Anthropic direttamente nelle impostazioni.
*   **🔀 Revisione Chirurgica (Diff):** Nessuna modifica "alla cieca". L'app mostra le modifiche proposte dall'IA con un Diff Rosso/Verde. Il file viene salvato solo quando premi "Accetta".
*   **📂 100% Locale:** I file di progetto vengono creati e modificati direttamente nella memoria del tuo smartphone. Non serve alcuna connessione a server cloud di terze parti.
*   **🐙 Git & SSH:** Clona repository da GitHub via HTTPS, fai commit, push/pull e collegati a server remoti (VPS) tramite SSH direttamente dall'app.

## ⚙️ Come Installare (Android)

Trattandosi di un'app scaricata fuori dal Google Play Store, il tuo smartphone Android potrebbe bloccare l'installazione iniziale per sicurezza. 

1. Scarica il file `.apk` dal link qui sopra.
2. Apri il file scaricato.
3. Se Android mostra un avviso di sicurezza, clicca su **Impostazioni** e abilita l'opzione **"Consenti da questa sorgente"** (o "Origini sconosciute").
4. Torna indietro e clicca su **Installa**.

## 🚀 Primi Passi
1. Apri l'app e vai nelle **Impostazioni**.
2. Incolla la tua **API Key** (es. Gemini o OpenAI).
3. Vai nella sezione **File**, crea un nuovo progetto e inizia a chattare con l'agente!
